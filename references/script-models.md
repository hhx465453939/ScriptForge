# 视频脚本模型库

本文件收录经过拆解验证的可复用脚本模型。每个模型包含框架结构、核心逻辑、适用品类和完形填空骨架。

> **持续更新规则:** 每次拆解出新的脚本模型时，对照本库。如为已有模型的变体，记录变体特征；如为新模型，按以下格式新增。

---

## 模型 1: 吐槽安利

**来源:** 水杯带货视频拆解
**内容类型:** 冲突类带货
**适用品位:** 全品类通用，尤其适合有明确对比场景的产品

### 框架结构（4层）

| 层级 | 功能 | 逻辑说明 |
|------|------|----------|
| 第一层 | 情绪吐槽钩子 | 用"吐槽"制造冲突，引发好奇（"什么东西这么气人？"）|
| 第二层 | 后悔对比+产品优势 | 建立新旧对比，制造后悔感，顺势引出产品卖点 |
| 第三层 | 场景延展+体验证言 | 用具体场景让用户脑补使用画面，增强代入感 |
| 第四层 | 价格暴击+行动指令 | 降价信息制造紧迫感，直接引导下单 |

### 核心逻辑

1. **吐槽钩子制造冲突:** "哑巴设计师"比"这款水杯真好用"冲击力强10倍，用户好奇"什么东西这么气人"
2. **后悔感建立对比:** "那我之前用不锈钢的，这算什么？"——用户代入"我也用错了"，比自夸有效
3. **痛点颗粒度极细:** 每个卖点对应真实痛点：掉漆、留味、漏、不能喝奶茶
4. **场景精准狙击:** "加粗吸管口还可以喝珍珠椰果"直接让目标人群脑补使用画面

### 完形填空骨架

```
[______身份]能不能不要当[______相关身份]？[______核心卖点]，你不能早点说吗？

那我之前一直用[______旧方案]的，这算什么？

[______功能1]，还特别[______功能2]，不容易[______痛点解决]。

就连[______产品部位]都是[______材质/特性]的，完全没有[______常见痛点]的烦恼。

一[______量词]就有[______数据]，完全可以[______效果]。

而且[______产品特点]还是[______设计特点]，[______扩展功能]还可以[______使用场景]，想[______]就[______]。

[______质量特性]很好，[______测试动作]都不会[______负面结果]的，[______场景]也很方便。

关键现在新品上市直掉[______价格]，快来直播间安排上。
```

| 品类 | 产品 | 效果 |
|------|------|------|
| 水杯 | 保温杯 | 原始案例，销量千单+ |
| 食品 | 即食鸡胸肉 | 仿写验证通过 |
| 美妆 | 养肤粉底液 | 仿写验证通过 |

## 模型 2: 痛点暴击

**来源:** 常见测评类视频拆解
**内容类型:** 测评/对比类
**适用品类:** 功能性强的产品（护肤品、家电、3C数码）

### 框架结构（4层）

| 层级 | 功能 | 逻辑说明 |
|------|------|----------|
| 第一层 | 痛点共鸣钩子 | 直击用户真实痛点，引发"就是我"的认同 |
| 第二层 | 方案悬念 | 引出产品但不说透，制造"到底是什么"的好奇 |
| 第三层 | 实测展示+对比 | 用具体数据和场景展示产品效果，新旧对比 |
| 第四层 | 信任背书+CTA | 用权威/数据/社会证明建立信任，引导下单 |

### 核心逻辑

1. **先痛后解:** 先让用户感受到痛点，再给出解决方案，效果远胜于直接推销
2. **数据说话:** 用具体数字替代模糊描述，增强可信度
3. **场景化验证:** 在具体使用场景中展示效果，而非空泛夸赞

### 完形填空骨架

```
[______痛点场景/困扰]，真的太[______负面感受]了。

直到我发现了这个[______产品名称]，[______悬念式效果描述]。

[______具体测试/使用场景]，[______数据/对比结果]。

而且[______权威背书/认证]，[______用户评价/销量数据]。

关键现在[______优惠信息]，快来[______行动指令]。
```

## 模型 3: 清单收割

**来源:** 常见好物推荐类视频拆解
**内容类型:** 种草/推荐类
**适用品类:** 适合多SKU展示、套装推荐、场景搭配推荐

### 框架结构（3层）

| 层级 | 功能 | 逻辑说明 |
|------|------|----------|
| 第一层 | 场景/人群钩子 | "XX人必备""租房党看过来"——精准圈人 |
| 第二层 | 逐条罗列+卖点 | 每件产品一个痛点+一个卖点，节奏紧凑 |
| 第三层 | 总结+行动指令 | 汇总价值，制造紧迫感，引导下单 |

### 核心逻辑

1. **精准圈人:** 开头直接筛选目标用户，非目标用户划走但目标用户必留
2. **数量冲击:** "N件好物"比单件推荐信息量大，完播率更高
3. **节奏感:** 逐条罗列形成固定节奏，用户形成预期

### 完形填空骨架

```
[______人群/场景]，这[______数量]件好物你必须知道。

第一件，[______产品名称]。[______痛点场景]，用它[______解决方案]。

第二件，[______产品名称]。[______痛点场景]，用它[______解决方案]。

第三件，[______产品名称]。[______痛点场景]，用它[______解决方案]。

这[______数量]件加起来才[______价格]，赶紧[______行动指令]。
```
