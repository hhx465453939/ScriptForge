# 爆款量化评估引擎 · 数学规范

> 本文件是 `scripts/viralmath/` 的**人性化说明书**：每个数学工具为什么选它、公式是什么、会踩什么坑、结果怎么读。
> 引擎代码是可执行的同一套逻辑；本文件是它的推理链。
>
> 核心立场：**爆款不是玄学，是一组可测量的分布特征**。但「可测量」不等于「可预测播放量」——
> 本引擎给的是**形态内相对位置**，不是播放量预言。这条线不许越。

---

## 0. 为什么要建这个引擎（现状审计结论）

改造前，项目的「爆款评估」是这样的：

| 层级 | 改造前 | 问题 |
|---|---|---|
| 评分 | 六维各打 1–10 分 | 无计算规则，换个人打就变 |
| 权重 | 六维等权相加 | 与平台「完播率最高权重」自相矛盾 |
| 归一化 | 无 | 10 分量表与真实分布无对应 |
| 基线 | 无 | 不知道 7 分算高还是低 |
| 不确定度 | 无 | 裸标量，假装精确 |
| 可复现 | 无 | 同一文案两次打分不同 |

这不叫量化，叫**打分表演**。本引擎要解决的是「量表背后没有模型」这个根因。

## 1. 五层流水线

```
原始文本
  │
  ├─① 特征层 features.py      可数出来的东西：分句/字数/句长序列/计数/词频
  │
  ├─② 指标层 info|rhythm|affect|align   数学变换：熵/JS/Zipf/Gini/ACF/OLS/CUSUM/马尔可夫
  │
  ├─③ 维度层 engine.dimensions()        7 个维度，全部归一化到 [0,1]，全部效益型
  │
  ├─④ 权重层 mcdm.py            AHP(主观先验,CR硬校验) + 熵权(客观区分度) → 组合赋权
  │
  └─⑤ 综合层 mcdm.topsis()      TOPSIS 贴近度 → score100；Bootstrap(BCa) → 95% CI
```

**可回溯铁律**：每一维的分数都能在输出的 `feature_trace` 里找到原始计数。找不到来源的数字不许出现在报告里。

## 2. 七个维度：工具 / 公式 / 陷阱 / 解读

> **口径诚实声明（rev1.3）**
> 七个维度**不等同于七个相互独立的证据**。
> - **结构层已去重**：每个维度内部不存在「同一统计量的两个标度」（如 Gini 与 CV、波动率与 CUSUM）。
> - **统计层未定论**：参考语料 n=12 上测得的有效维度约 3.5，该数字**不可作结论**，仅说明七维不等于七个独立方向。
> - 复核命令：`python scripts/dim_audit.py`（块2 精确、块3/4 需 n≥30）。细节见 §2.6。

### D1 钩子力 `hook`

- **工具**：Surprisal（信息论）+ 钩子词表加权命中 + 前 3 句标点强度
- **公式**：
  - `s₁ = min(1, Σ(钩子命中×类型权重) / 2.5)`
  - `s₂ = min(1, 首句平均 surprisal / 9.0 bits)`
  - `s₃ = min(1, 前3句问号+感叹号数 / 2.0)`
  - `hook = 0.45·s₁ + 0.30·s₂ + 0.25·s₃`
- **surprisal 定义**：`−log₂ p(token)`，p 用 Lidstone 平滑 `(c+0.5)/(N+0.5V)`
- **陷阱**：
  1. `p=0` 时 surprisal 发散为 ∞ → 必须平滑后再取对数（代码里 eps 下限双保险）
  2. 对数底数混用会让「bits」变成「nats」→ 全库统一 **base=2**
  3. 小样本下词频概率估计偏差大 → 平滑 + 明示这是**本文内部相对惊喜度**，不是市场新鲜度
- **解读**：高 = 开头有信息缺口或冲突；低 = 开头是铺垫/自我介绍，前 3 秒在流失。

### D2 信息密度 `density`

- **工具**：信息单元密度 + 归一化词汇熵 + Zipf 幂律拟合
- **公式**：
  - `s₁ = min(1, 每百字信息单元数 / 12)`，信息单元 = 数字 + 信任锚词 + 钩子词
  - `s₂ = min(1, H_norm / 0.95)`，`H_norm = H(X)/log₂|V|`
  - `s₃ = min(1, α_zipf / 1.10)`
  - `density = 0.45·s₁ + 0.35·s₂ + 0.20·s₃`
- **Zipf 拟合**：`freq ∝ rank^(−α)`，对 `log freq ~ log rank` 做 OLS
- **陷阱**：
  1. **熵的单位**：`0·log0` 约定为 0，求和前剔除零概率项
  2. **熵不是越高越好**：全随机字符串熵最高但没人看。本项用「相对基线的归一化熵」，且权重只占 0.35
  3. **Zipf 只在中间区段线性**，尾部噪声大 → 必须回带 R²；**R² < 0.70 时直接剔除该项权重**，把权重按比例分给前两项，不许硬用
  4. 长文本词汇天然更丰富 → 用「每百字」而非绝对计数做密度，避免长文刷分
- **解读**：高 = 单位时间给的信息多、记忆锚集中（α 大=流量集中在少数词）；低 = 车轱辘话。

### D3 节奏冲击 `rhythm`

- **工具**：Gini 系数 + 变异系数 CV + MAD 稳健 CV + 自相关 + DFT 主周期
- **公式**：
  - `s₁ = min(1, Gini(句长) / 0.45)`
  - `s₂ = min(1, CV(句长) / 0.75)`
  - `s₃ = min(1, 主周期能量占比 / 0.35)`，句数 <20 时取中性 0.5
  - `rhythm = 0.40·s₁ + 0.35·s₂ + 0.25·s₃`
- **陷阱（全部是实测踩过的）**：
  1. **ACF/DFT 在短序列上不可信** → 硬性最小样本门 `n ≥ 20`，否则 `reliable=False` 并在报告里标注
  2. **DFT 必须先扣均值**，否则 DC 分量吞掉全部能量
  3. **不加窗会频谱泄漏** → 加 Hann 窗
  4. **取全局最大峰 ≠ 取基频**：脉冲串（长短短短重复）的频谱是**等幅多阶谐波**，argmax 会被浮点误差选到高次谐波。实测 `[1,0,0,0]×6` 曾把周期误报为 **2.0**（真值 4.0）
  5. **加窗后主峰展宽到 ±1 bin**，若只取「首个超过 50% 峰值的 bin」会锁到**裙边**，周期误报 4.8（真值 4.0）→ 最终必须**先取局部极大值**，再在其中取最低频且 ≥50% 峰值者
  6. **CV 怕离群值** → 双报 MAD 稳健 CV。注意：**超过 50% 样本相同时 MAD=0**，这是稳健性的正确表现，不是算错
- **解读**：高 = 长短句反差强、有节拍；低 = 句式均质，听着像念稿。

### D4 情绪驱动 `emotion`

- **工具**：情绪词典序列 → 波动率 + OLS 斜率 + CUSUM 变点
- **公式**：
  - `s₁ = min(1, σ(情绪序列) / 0.55)`
  - `s₂ = min(1, |OLS 斜率| / 0.06)`
  - `s₃ = min(1, CUSUM 最大统计量 / 6)`
  - `s₄ = min(1, 每百字情绪词数 / 6)`
  - `emotion = 0.28·s₁ + 0.24·s₂ + 0.20·s₃ + 0.28·s₄`
- **陷阱**：
  1. **伪回归**：非平稳序列直接回归会得到虚假显著 → 本项只做**趋势描述**，t 值仅作辅助读数并强制回带，不据此断言因果
  2. **斜率不报不确定度** → 强制回带 `se / t / r²`
  3. **CUSUM 阈值隐含** → `h` 与漂移 `k` 全部外露为参数并写入 trace
  4. 情绪词表是人工词典，对反讽/留白无感 → 这是已知盲区，见 §8
- **解读**：高 = 情绪有起伏且有转折点；`arc_type=上升` 通常比 `平` 更抓人。

### D5 说服转化 `persuasion`

- **工具**：信任锚密度 + 数字密度 + CTA 位置收益衰减 + 合规扣分
- **公式**：
  - `s₁ = min(1, 每百字信任锚/4)`、`s₂ = min(1, 每百字数字/3)`
  - `s₃ = min(1, CTA 命中/2) × (0.85 + 0.15·CTA相对位置)`（越靠后越接近 1，但下界 0.85）
  - `persuasion = max(0, 0.40·s₁ + 0.30·s₂ + 0.30·s₃ − min(0.30, 0.05·绝对化用语数))`
- **陷阱**：
  1. **绝对化用语是负资产**：`最好/第一/永久/根治` 违反广告法，转化再好也不可持续 → 扣分而非加分
  2. CTA 位置用「相对位置」而非绝对句号，避免长短文不可比
- **解读**：高 = 有数据、有背书、有明确行动指令且合规；低 = 只抒情不给证据。

### D6 差异化 `distinction`

- **工具**：Jensen–Shannon 散度 + **词表规模噪声地板校正**
- **公式**：
  - `JS(P‖Q) = H((P+Q)/2) − [H(P)+H(Q)]/2`，base=2，取值 ∈[0,1] bit
  - `floor = median{ JS(P, resample(Q, |P|)) }`（从基线自身重采样等长样本，40 次）
  - `excess = max(0, JS − floor)`
  - `distinction = min(1, excess / 0.65)`
- **为什么不用 KL**：KL 不对称（`D(P‖Q) ≠ D(Q‖P)`）、且当 Q 在 P 支撑外取零时**发散为 ∞**。JS 对称、有界，可直接当距离用。
- **为什么必须扣 floor（本项目最重要的实测修正）**：
  - 参照语料每形态只有 3 段、约 700 字。任何几百字的真实文本与它相比，都会因**词表覆盖度差异**产生很大的 JS，这个量与风格无关。
  - 实测：形态内参照文本自比 JS ≈ 0.47；300 字真实样本 JS ≈ 0.87。
  - 若不校正、cap 取 0.45，则**所有输入都饱和到 1.0**，该维度变成零信息量的假指标。
  - 校正后实测分离度：**形态内 excess ≈ 0（−0.04 ~ −0.02）**，**跨形态 excess ≈ 0.53 ~ 0.79**，样本落在 0.18 ~ 0.56 —— 真正有区分度。
  - 试过 top-K 截断，反而更糟（截断后两分布近乎不相交，in-ref 中位数升到 0.78~0.86）。**记录在此以免后人重走**。
- **陷阱（残留）**：JS 随文本变长而上升，所以本项**偏袒长文**；跨形态比较无意义（基线的基线不同）。跨形态差异见 §8。
- **解读**：高 = 用词/结构与同形态大盘明显不同（有记忆点）；低 = 高度同质，容易被划走。

### D7 可复制性 `replicability`

- **工具**：一阶马尔可夫链熵率
- **公式**：
  - 结构状态序列（每句标为 `hook/pain/claim/evidence/cta/other`）
  - `H_rate = Σᵢ πᵢ·H(Pᵢ·)`，`H_max = log₂K`
  - `determinism = 1 − H_rate/H_max`
  - `replicability = determinism`；转移样本 <10 时折减 ×0.6 并标低置信
- **陷阱**：
  1. **转移概率必须按行归一化**（除以该行计数和），否则不是概率分布
  2. **转移样本少时转移概率纯属噪声** → 硬性 `n_transitions ≥ 10` 门
  3. π 用经验边缘分布 plug-in，不是平稳分布解 → 短序列下有偏，已在报告中标注
- **解读**：高 = 结构套路固定，运营容易照抄；低 = 每次结构都不同，难复制但可能更难被算法归类比价。

## 2.6 共线性审计（rev1.3 新增）

「不共线」不能是作者的口头结论，必须可被第三方复现。工具：`python scripts/dim_audit.py`。

### 四块输出

| 块 | 内容 | 依赖数据 | 可信度 |
|---|---|---|---|
| 1 源依赖矩阵 | 行=数据源，列=七维，值=该维从该源取了几项子指标 | 否 | **精确** |
| 2 违规检测 | 同维内出现「同源同方面」两项 → FAIL | 否 | **精确** |
| 3 相关矩阵 | 七维两两 Pearson r（**去体裁均值版为准**，混池版仅参考） | 是 | n<30 时仅作健全性检查 |
| 4 有效维度 | 相关矩阵特征值谱 + 参与率 | 是 | 同上 |

### 为什么相关矩阵要给两个版本

混池相关会把**体裁效应**误当**维度冗余**：video 句子短、text 句子长，混在一起算相关，
hook 与 rhythm 会出现很高的表面相关，但它们在同一个体裁内部并不冗余。
所以工具同时给「混池」与「去体裁均值」，**以去体裁版为准**。

### 实测去重效果（rev1.0 → rev1.3）

| 项 | rev1.0 | rev1.3 | 处理 |
|---|---|---|---|
| 块2 违规 | — | **0（PASS）** | 无同源同标度 |
| `density ↔ hook` | 0.66 | 0.29 | 钩子词不再同时进 D1/D2 |
| `density ↔ emotion` | 0.87 | -0.02 | 情绪词密度移出 D4 |
| `density ↔ persuasion` | 0.79 | -0.08 | 数字归 D2、信任锚/CTA 归 D5 |
| 去体裁均值参与率 | 3.28 | 3.476 | 有效维度略升 |
| `rhythm ↔ distinction` | — | **0.906（未解决）** | 假设两者都在代理「文本不寻常度」；n=12 无法裁决 |

### 结论与边界

- **结构层结论可用**：块1/块2 不依赖样本，任何语料下结论都成立。
- **统计层结论待定**：n=12 太小（其中 text 组仅 2 样本），相关矩阵与参与率只能作方向性提示。
- **不得做的事**：把「参与率 3.476」写成「模型只有 3.5 个维度」发布——它需要 n≥30 才能主张。

## 3. 权重层：AHP × 熵权 → 组合赋权

### 3.1 AHP（主观先验，可审计）

- 每形态一份 7×7 判断矩阵（Saaty 1–9 标度，互反 `a_ji = 1/a_ij`）
- 主特征向量 = 权重：用**幂迭代**（Perron–Frobenius，正矩阵主特征向量唯一为正）
- `λmax` 用 **Rayleigh 商 λ = vᵀAv，且要求 ‖v‖₂ = 1**
- `CI = (λmax − n)/(n − 1)`，`CR = CI / RI`，RI 用 Saaty 表（n=7 → 1.32）
- **硬门控**：`CR > 0.1` 直接抛 `InconsistentMatrixError`，不许静默放行

**踩过的坑（必须记住）**：最初幂迭代用**和归一化**（L1），Rayleigh 商公式在 `‖v‖₂=1` 才成立，
结果 λmax 被压到 **1.07**（7×7 矩阵理论上必须 ≥7），`CI` 变负、`CR` 恒为 0 ——
**一致性门控彻底失效，而且不报错**。这是静默错误，比崩溃危险得多。
现已修复并加了回归测试 `test_ahp_lam_ge_n`。

### 3.2 熵权法（客观区分度）

- 对 m 个参照原型 × n 个维度：`p_ij = x_ij/Σᵢx_ij`，`e_j = −(1/ln m)Σ p ln p`，`d_j = 1−e_j`，`w_j = d_j/Σd_j`
- **陷阱**：某维度在所有原型上取值相同 → `e_j=1` → `d_j=0`；若全部 `d_j=0` 则分母为零 → **必须回退均权**，不许除零

### 3.3 组合赋权

- `w = α·w_AHP + (1−α)·w_熵权`，再归一化；本项目 α = 0.55（略偏主观先验）
- 为什么组合：纯主观会把「我的偏见」包装成数学；纯客观会让「参照原型恰好没差异」的维度权重归零

## 4. 综合层：TOPSIS 贴近度

- 方案集 = {本文} ∪ {5 个参照原型：顶配/优秀/中等/偏弱/差}
- 步骤：向量归一化 `r_ij = x_ij/√Σx²` → 加权 `v_ij = w_j·r_ij` → 正/负理想解 → 距离 → `C* = d⁻/(d⁺+d⁻)`
- `score100 = 100·C*`，分区 S≥80 / A≥65 / B≥50 / C≥35 / D<35
- **陷阱**：
  1. 不做向量归一化 → 量纲大的维度霸占全部权重
  2. 成本型/效益型方向必须显式声明（本项目 7 维全是效益型，方向统一）
  3. `d⁺+d⁻ = 0` 时贴近度无定义 → 回退 0.5
- **为什么用 TOPSIS 而不是加权求和**：加权求和得到的是「绝对水平」，但爆款是**相对竞争**——
  TOPSIS 给的是「离理想有多远、离最差有多远」的相对位置，更贴合「形态内分位」的语义。

### 4.5 附加定位输出（不是七维的一部分）

七维答不了两个问题：「这个水平算好还是差」与「情绪怎么走」。三个附加指标补位，
**测度选择都是踩过坑后定下的**：

| 字段 | 测度 | 回答 | 选型理由（关键） |
|---|---|---|---|
| `archetype_match` | `1 − ‖dims−arch‖/√n`（归一化欧氏距离） | 「处于哪个水平」 | **水平问题必须用距离**。七维全为非负且量级相近，余弦只测夹角不测水平——实测把 C 区样本算成「最像**差**原型，cos=0.977」，结论完全错误。 |
| `profile_fit` | `cos(dims, 形态先验权重)` | 「力气是否花在本形态最看重的维度上」 | **形状问题用夹角**。要比较的是「分数分布形状」与「权重优先序」是否同向，这正是余弦的适用范围。 |
| `arc_alignment` | DTW（除以路径长归一化） | 「情绪弧怎么走」 | 七维只量情绪**强度**，不量**走向**；同强度的上升弧与坠落弧分数无差别，但传播效果差很多。已除以路径长，否则长文永远更不像。 |

**一句话记忆：水平用距离，形状用夹角，走向用对齐。** 三者用错就会出「cos=0.977 却判成最差」那类错。

**实测对照（三形态样本）**：

| 样本 | 综合分 | 最像原型（距离法） | 权重契合（余弦） | 弧对齐（DTW） |
|---|---|---|---|---|
| video | 41.8 (C) | 中等 0.815 | 0.875 | 0.788 |
| graphic | 37.4 (C) | 偏弱 0.775 | 0.902 | 0.773 |
| text | 29.1 (D) | 偏弱 0.753 | 0.766 | 0.769 |

自洽性检验：分数低的样本落到更低等级原型（29.1→偏弱），说明距离法与分区分层同向；若出现「低分却最像顶配」即为测度出错。

## 5. 不确定度层

### 5.1 Bootstrap BCa（综合分与各维区间）

- 重采样单位 = **句子**（句级 bootstrap），重算全链 400 次（可调）
- 默认 **BCa**（偏差校正 + 加速），因为小样本下百分位 bootstrap 覆盖率偏低
- 偏差校正 `z₀ = Φ⁻¹(#{θ*<θ̂}/B)`；加速 `a` 用 jackknife 三阶矩
- **陷阱**：`prop=0 或 1` 时 `z₀` 发散 → 截断到 `[1/(2B), 1−1/(2B)]`；加速项分母为 0 时退化为偏差校正百分位
- 标准库无 Beta/正态分位 → 用 `statistics.NormalDist`，Beta 分位自建（Lentz 连分式 + 二分）

### 5.2 Beta-Binomial 后验（达标率类问题专用）

- `Beta(a₀+s, b₀+n−s)`，均匀先验 `Beta(1,1)`
- **陷阱**：0 次成功/全成功时，频率派会给出 0% 或 100% 的假精确；后验区间天然有界，不会触碰 0/1
- 用于「N 篇里 K 篇达标」这类小样本率估计（如校准阶段）

## 6. 复现性

- 所有随机过程接受 `--seed`，默认 `20260101`
- 同输入 + 同 seed → 输出**逐字节一致**（有回归测试 `test_determinism`）
- JS 噪声地板有缓存（按「基线规模 + token 数分桶」），既提速又保证同输入必同结果
- 逐维区间与总分区间用**不同 seed**（`seed+1`），避免共用同一批重采样样本造成伪相关

## 7. 校准协议（当前状态：`CALIBRATION_PENDING`）

现状必须说清楚：**所有词表、caps 饱和上限、参照原型、分区阈值都是人工先验**，没有一条来自真实数据。

### 校准步骤（拿到数据后照做）

1. **集语料**：每形态 ≥100 条**已发布且有真实数据**的内容（完播率/互动率/收藏率/转化率至少一项）
2. **替换参照语料**：把 `calibration.REFERENCE_CORPUS` 换成真实语料抽样（建议每形态 200 条，控制长度分布）
3. **重估 caps**：对每个子指标取真实语料分布的 **P90** 作为饱和上限（而不是现在的拍脑袋值）
4. **重估 AHP 先验**：用真实数据做单变量回归（各维度 → 实际指标），把标准化 β 作为先验权重的依据，再转 Saaty 标度
5. **重估分区阈值**：用真实综合分的 P90/P70/P50/P30 作为 S/A/B/C 分界
6. **验证分离度**：要求「高表现组 − 低表现组」的综合分差 ≥ 15 分，否则说明维度没抓住信号
7. 把 `calibration_status` 改为 `CALIBRATED vN`，并在本文件追加「实测校准记录」

### 校准前禁止的事

- 禁止拿本引擎分数对外宣称「这条会爆」
- 禁止跨账号比较（不同账号粉丝基数、平台流量池不同）
- 禁止跨形态比较绝对值（三形态权重档不同）

## 8. 已知盲区（诚实清单）

| 盲区 | 影响 | 为什么不做 |
|---|---|---|
| 图片/视频画面不解析 | 图文的「首图钩子」只能吃用户文字描述 | 无 OCR/抽帧依赖，保持零依赖 |
| 中文本分词用「字符二元组」近似 | 句法级特征做不了 | 避免引入 jieba；分布型指标不受影响 |
| 情绪词典对反讽/留白无感 | 高级幽默文案会被低估 | 无标注数据训练情绪模型 |
| JS 对文本长度敏感 | D6 偏袒长文 | 已用地板校正缓解；彻底解法是加大基线语料 |
| 不预测播放量 | 不能当投放决策依据 | 无因果识别，只有形态内相对位置 |
| 「可复制性」只用结构状态转移 | 抓不到语气/人设可复制性 | 人格化特征无法用马尔可夫表达 |

## 10. 怎么用（给 agent 的调用协议）

```bash
# 单条打分（Markdown 报告）
python scripts/viral_score.py --file 文案.txt

# 结构化输出（含 feature_trace，便于二次加工）
python scripts/viral_score.py --file 文案.txt --json

# 快速模式（关掉置信区间，约 0.01s）
python scripts/viral_score.py --file 文案.txt --boot 0

# 指定形态（自动判定低置信时用）
python scripts/viral_score.py --file 文案.txt --genre graphic
```

**解读纪律（写报告时必须遵守）**：

1. 报分必须带区间：`41.8（95% CI 33.7–50.1，BCa，B=400）`，不许只写 `41.8`
2. 报分必须带形态：video 的 60 分 ≠ graphic 的 60 分
3. 短板必须给可执行改法：不是「情绪驱动低」，而是「第 3–5 句情绪词为零，建议插入一个具体痛点场景」
4. 出现 `reliability_notes` 时必须转述给用户，不许吞掉
5. 禁止输出「本分预测播放量约 X」
