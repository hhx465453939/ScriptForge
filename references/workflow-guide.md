# 多形态内容拆解与仿写 - 工作流执行指南

本文件定义了内容拆解与仿写引擎的完整执行流程。AI 必须严格按照以下 Phase 顺序执行，确保每次拆解输出完整、规范、可复用。

> 形态差异规则（video / graphic / text）的唯一承载点是 `references/content-genres.md`。本文件只做**路由**，不重复规则。

---

## Phase 0: 形态判定（不可跳）

### 为什么要先判形态

口播的杀手锏是前 3 秒，图文的是标题与首图，长文的是论证与可检索性。用口播规则套图文，等于用体温计量身高。

### 执行

1. 跑 `python scripts/genre_probe.py --file <内容文件>`（或读入文本后调 `viralmath.features.detect_genre`）
2. 得到 `形态 + 置信度 + 判定依据`
3. 在报告首行输出形态声明：`形态：xxx　置信度：高/中/低　依据：……`
4. **低置信度必须提示用户可覆盖**（兜底规则命中时）
5. 用户显式声明形态 → 直接采用，覆盖自动判定

### 判定规则

见 `references/content-genres.md` §2（优先级短路表）。核心：口播元标记 → 标签/@ → 小标题/图表引用 → 口语称呼+短句 → 兜底。

## Phase 1: 接收与感知

### 输入要求

用户提供**任一形态的完整内容**。最小启动条件随形态变化：

| 形态 | 最小启动条件 |
|---|---|
| video | 完整口播文案 |
| graphic | 标题 + 正文（首图描述可选） |
| text | 标题（可选）+ 正文 |

**可选补充信息（如用户未提供则自行判断）:**
- 产品名称/品类
- 目标平台（抖音/小红书/快手/公众号/知乎等）
- 希望仿写的品类或目标形态
- 视频时长 / 图文字数 / 长文篇幅限制
- 风格偏好

### 内部处理（不直接输出）

通读全文，建立整体感知:

1. 这是什么品类/产品/论题？
2. 目标用户是谁？
3. 整体调性是什么？（种草/测评/观点/叙事/教程/混合）
4. 预估消费时长（video 秒数 / graphic 滑动屏数 / text 阅读分钟）
5. 第一直觉：这条内容的"杀手锏"是什么？

## Phase 2: 五层深度拆解

> **形态路由**：五层通用层（钩子/结构/逻辑/亮点/评估）三形态共用；另需在本 Phase 末尾追加**形态专属层**。
>
> | 形态 | 专属层板块 | 规则位置 |
> |---|---|---|
> | video | 钩子时间轴、口播节奏 | `content-genres.md` §3.1 |
> | graphic | 标题公式、首图钩子、分段节奏、标签策略 | `content-genres.md` §3.2 |
> | text | 论点链、论证结构、金句密度、长文钩子 | `content-genres.md` §3.3 |

### 2.1 钩子雷达（HookRadar）

**目标:** 识别文案中所有的钩子设计。

**钩子类型库（12种）:**

| 类型 | 定义 | 示例特征 |
|------|------|----------|
| 痛点钩 | 直击用户焦虑 | "你是不是也..." |
| 利益钩 | 前置价值承诺 | "只用了一周就..." |
| 悬念钩 | 制造信息缺口 | "千万别买..." |
| 冲突钩 | 观点对立/反常识 | "哑巴能不能不要当设计师？" |
| 身份钩 | 圈定精准人群 | "姐妹们..." |
| 场景钩 | 唤醒具体画面 | "每天早上洗完脸..." |
| 数据钩 | 数字制造冲击 | "39块钱，洗完脸滑得..." |
| 权威钩 | 借势背书 | "大牌代工厂出的" |
| 恐惧钩 | 损失厌恶触发 | "再不买就涨了" |
| 共鸣钩 | 情感共振 | "我真的受够了..." |
| 热点钩 | 借势时事/流行梗 | 结合当下热点 |
| 对比钩 | before/after冲击 | "一个月前还全是...现在..." |

**输出格式:**

```
| 序号 | 钩子类型 | 原文标注 | 强度(S/A/B/C) | 改进方向 |
```

### 2.2 骨架扫描（BoneScanner）

**目标:** 透视文案的叙事结构骨架。

**识别框架库:**

| 框架 | 结构 | 典型应用 |
|------|------|----------|
| 经典带货五段式 | 黄金3秒→痛点→方案→证据→转化 | 通用带货 |
| AIDA | 注意→兴趣→欲望→行动 | 品牌种草 |
| PAS | 问题→激化→解决 | 痛点切入 |
| FAB | 特征→优势→利益 | 产品介绍 |
| 故事弧 | 冲突→挣扎→转折→解决 | 剧情类 |
| 清单体 | 总起→逐条罗列→收束 | 好物推荐 |
| 测评体 | 提问→实测→结论 | 测评对比 |
| 吐槽安利 | 吐槽钩子→后悔对比→功能陈述→场景延展→价格暴击 | 冲突类带货 |

**输出格式:**

```
| 段落 | 文案内容（摘录） | 功能标注 | 隐藏卖点 | 情绪手法 |
```

**框架结构表:**

```
| 层级 | 功能 | 对应文案 |
```

### 2.3 逻辑还原（LogicChain）

**目标:** 还原用户从"不知道"到"想买"的心理操控路径。

**分析维度:**
- **认知路径:** 用户经历了哪些心理转折
- **信任建构:** 哪些节点埋设了信任锚（数据/案例/权威/社会证明）
- **欲望激发:** 哪些句子制造"我也要"的冲动
- **行动催化:** CTA设计是否有效

**输出:** 文字版逻辑链流程图 + 每环节效力评分

### 2.4 亮点挖掘（GemFinder）

**目标:** 标注文案中值得复用的高价值元素。

| 类型 | 说明 | 价值 |
|------|------|------|
| 金句/记忆点 | 可直接搬用的表达 | 用于仿写开头/结尾 |
| 情绪高潮点 | 最能引发共鸣的瞬间 | 用于完形填空骨架保留 |
| 信息差/认知颠覆 | 让人"原来如此"的信息 | 用于内容深度 |
| 视觉化表达 | 文字转画面感极强的段落 | 用于分镜设计 |
| 节奏设计亮点 | 停顿、重复、排比等修辞技巧 | 用于仿写节奏参考 |

**输出格式:**

```
| 原文标注 | 亮点类型 | 复用建议 |
```

### 2.5 爆款潜力评估（ViralMeter）

**目标:** 多维度评估文案的爆款概率。

**评估维度（每项1-10分）:**

| 维度 | 评估重点 |
|------|----------|
| 前3秒留人力 | 完播率基础 |
| 信息密度与节奏感 | 中段留存 |
| 情绪驱动力 | 互动/转发动力 |
| 转化说服力 | 带货转化潜力 |
| 差异化程度 | 内容辨识度 |
| 可复制性 | 仿拍难度 |

**输出:** 六维评分 + 总分 + 核心优势 + 致命短板

## Phase 3: 模型提炼与命名

### 提炼规则

1. 从骨架扫描结果中提取3-5层框架结构
2. 归纳每一层的功能、对应的情绪/心理作用
3. 总结模型生效的核心逻辑（为什么能跑量）
4. 与 `references/script-models.md` 中的已有模型匹配

### 命名规则

- **4字命名**，要求: 直观、好记、体现核心特征
- 格式: [动作/情绪] + [功能/结果]
- 示例: 吐槽安利、后悔种草、痛点暴击、场景带入、清单收割

### 输出内容

```
模型名称: XXXX
框架结构:
  - 第一层: [功能] — [对应文案/逻辑]
  - 第二层: [功能] — [对应文案/逻辑]
  - ...
核心逻辑:
  - 逻辑1: [说明]
  - 逻辑2: [说明]
适用品类: [品类列表]
```

## Phase 4: 完形填空模板输出

> ⚠️ **这是核心交付物。所有拆解任务必须输出。测评类/种草类/清单类为强制输出。**
>
> **形态路由**：留空位随形态不同（规则与示例见 `references/fill-blank-guide.md`）：
> - video：产品名/卖点/数据/价格
> - graphic：**额外必含标题公式位、首图钩子位、正文分段位、标签位**（四类齐备）
> - text：论题/证据数据/限定条件/结论动词

### 生成规则

详细规则参见 `references/fill-blank-guide.md`，核心原则:

**保留（不替换）:**
- 转折词和连接词（"但是""而且""就连"）
- 情绪表达框架（"你不能早点说吗？""这算什么？"）
- 逻辑句式结构（条件句、对比句、反问句）
- 通用金句和节奏设计
- CTA句式（"快来直播间安排上"）

**留空（用 `[______]` 占位）:**
- 产品名称/品类
- 具体卖点、功能描述
- 具体数据（容量、价格、克数等）
- 产品特有材质/成分
- 与特定产品绑定的场景

### 输出格式

参见 `references/fill-blank-guide.md` 中的标准输出格式和示例。

## Phase 5: 仿写脚本输出

### 触发条件

- 用户指定品类时: 按指定品类仿写
- 未指定时: 自动推荐2-3个适合该模型的品类，每个品类输出完整仿写

### 仿写规则

1. **保留:** 核心框架结构、逻辑链、情绪节奏、钩子句式
2. **替换:** 产品信息、卖点描述、具体数据、使用场景、价格信息
3. **适配:** 根据品类特性调整表达方式和场景描述
4. **验证:** 仿写文案读起来自然流畅，不生硬

### 输出格式

每个品类输出一段完整的口播文案，标注:
- 适用的产品名称
- 视频预估时长
- 预期效果说明

## Phase 6: 知识分享文案（可选）

### 触发条件

用户明确要求时触发（如"帮我写一条分析这个模型的口播文案"）。

### 输出要求

以短视频运营博主的身份撰写口播文案:
- 开头直接给结论/方法
- 用仿写案例演示模型
- 结尾给金句总结
- 语言风格: 干货感强、节奏快、口语化

---

## 质量检查清单

每次输出前，对照以下清单确认:

- [ ] 基础判断是否完整（6个维度）
- [ ] 钩子拆解是否覆盖所有钩子类型
- [ ] 结构解码是否清晰标注每段功能
- [ ] 逻辑链是否还原完整心理路径
- [ ] 亮点标注是否标注了所有可复用元素
- [ ] 爆款评估是否六维打分完整
- [ ] **完形填空模板是否已输出**（核心）
- [ ] 完形填空的每个占位符是否有填写说明
- [ ] 仿写脚本是否保留了核心结构
- [ ] 如有多条文案，是否启用了对比模式
