## 0.1 原始需求（Owner 原话）

> 在开发过程中，增加一个核心，就是 /math 技能里面，试着抓几个数学工具，然后看看，能不能对于爆款拆解这件事，无论是视频文案还是图文文案，都能够建立起来基于数学模型的量化评估引擎，然后把这个引擎的逻辑，写入这个项目，这样，在使用这个项目的 agent 眼里，一切爆款皆存在规律以及可用于分析的数学工具。

## 0.2 现状审计（实测）

| 事实 | 证据 |
|---|---|
| 现有「爆款评估」是拍脑袋六维打分 | `references/workflow-guide.md` §2.5：六维「每项 1-10 分」，**无任何计算规则**，无权重来源、无归一化、无参考基线、无不确定度 |
| 权重无来源 | `platform-insights.md` 说「完播率最高权重」，但六维里「前3秒留人力」与其他五维等权相加，自相矛盾 |
| 无任何可执行代码 | `scripts/` 两个文件均为「[已废弃]」6 行占位 |
| 无刻意练习/校准机制 | 全库无「历史样本对标」「分数校准」概念 |
| 「亮点标注」「钩子强度 S/A/B/C」纯主观 | 无判定阈值定义 |

**结论（根因）**：所谓「量化」只有 1-10 分的**量表外壳**，量表背后没有模型。分数不可复现、不可比较、不可解释——同一个文案换个人打就变。这不叫量化，叫打分表演。

## 0.3 目标形态

建立一个**可执行、可复现、带不确定度**的评估引擎：

```
文本 → 特征层（可数出来的量）→ 指标层（数学变换）→ 维度层（6/7 维）→ 权重层（AHP+熵权组合）→ 综合分（TOPSIS 贴近度）→ 区间（Bootstrap）
```

三个硬要求：
1. **可复现**：同样输入 + 同样 seed → 同样数字，误差 < 1e-9
2. **带误差棒**：每个综合分必须给 Bootstrap 置信区间，禁止裸标量
3. **可解释**：每个维度必须能回溯到特征层的原始计数

## 1. 范围

### 1.1 In Scope

- 特征抽取（纯标准库）：分句、字数、句长序列、数字/问号/感叹号/第二人称/否定/绝对化/CTA/信任锚/情绪词计数
- 数学变换：香农熵、Surprisal、JS 散度、Zipf 幂律拟合、Gini、CV、MAD 稳健 z、ACF、FFT 主周期、OLS 斜率、CUSUM 变点、马尔可夫熵率、余弦、DTW
- 多维综合：AHP（特征向量 + CR 检验）、熵权法、组合赋权、TOPSIS
- 不确定度：Bootstrap（BCa）、Beta-Binomial 后验区间
- 三形态权重档（video/graphic/text）
- CLI：`scripts/viral_score.py`
- 参考文档：`references/math-engine.md`（公式 + 陷阱 + 解读协议）

### 1.2 Out of Scope

- 不用 numpy/scipy/sklearn（保持零依赖；纯标准库实现）
- 不做机器学习训练（无标注数据，禁止假装有监督模型）
- 不预测真实播放量（禁止伪造因果，只做「形态内相对分位」）
- 不替代人工判断（引擎给「分区 + 短板」，不给「必爆」结论）

## 2. 数学工具选型（经 /math 四层路由）

信号识别：**多维文本特征 → 综合评分 + 权重客观化 + 不确定性 + 语料对标**。

| 维度 | 工具 | 种子库锚点 | 必防陷阱（已读条目） |
|---|---|---|---|
| 钩子力 | Surprisal −log p | C7 信息论 | 小样本概率估计偏差 → 加性平滑 + Miller–Madow 校正 |
| 差异化 | Jensen–Shannon 散度 | C7 KL 条目 | **KL 不对称且零支撑发散 → 用 JS（对称、有界 log2）** |
| 记忆点集中度 | Zipf 幂律 log–log OLS | C3 回归 | log–log 仅中段线性，尾部噪声 → 必须报 R²，R²<0.7 标注「拟合不可信」 |
| 节奏冲击 | Gini / CV / MAD 稳健 z | C2 描述统计 | CV 惧异常值 → 双报 CV 与 MAD-CV |
| 节奏周期 | ACF + FFT 主周期 | B8 信号 | 序列短于 20 句 ACF 不可靠 → 硬性最小样本门；FFT 泄漏 → 加 Hann 窗 |
| 情绪弧 | OLS 斜率 + CUSUM 变点 | C3/C6 | 伪回归风险 → 斜率必报 t 值；CUSUM 阈值 h 显式外露 |
| 权重（主观） | AHP 特征向量 + CR | A2 特征值（`np.linalg.eig`） | **AHP 本身种子库无专条 → 自建；CR>0.1 必须拒绝并告警** |
| 权重（客观） | 熵权法 | C7 熵 | 指标等值时熵→1，权重→0 分母除零 → 加 ε 保护 |
| 综合排序 | TOPSIS | 种子库无专条 → 自建 | 成本型/效益型方向必须显式声明；须先向量归一化 |
| 不确定度 | Bootstrap BCa + Beta 后验 | C2/recipes/06 | 小样本 bootstrap 覆盖率偏低 → 用 BCa；seed 固定保复现 |
| 模板对齐 | 余弦 + DTW | D3 动态规划 | DTW 距离依赖路径长度 → 必须除以路径长归一化 |
| 可复制性 | 马尔可夫熵率 | C5 马尔可夫链 | 转移矩阵须行归一化；状态样本 <10 时熵率不可信 → 标注低置信 |

**诚实声明**：AHP / TOPSIS / 熵权法 / DTW 在 math 种子库中**无专条**，本 CHG 按标准定义自建实现，并在 `references/math-engine.md` 为它们补写陷阱字段——不冒充库内工具。

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| 「数学」沦为装饰：公式很唬人，输出不可用 | 每个维度必须能回溯到特征层原始计数，报告强制打印 feature trace |
| 假精确：小数点后四位但无意义 | 分数只报 1 位小数 + 区间；总分必须带 CI |
| 权重拍脑袋套数学外衣 | AHP 判断矩阵必须外露在 `genres.py` 且 CR 硬校验；客观熵权必须参与组合，不能纯主观 |
| 过拟合到我自己造的样本 | 全部基线（词表、阈值）标记 `CALIBRATION_PENDING`，并在文档写明「需用真实爆款语料重校准」 |
| 用户把分数当播放量预测 | 报告强制加免责段：本分仅为形态内相对位置，非播放量预测 |

## 4. 成功判据

1. `python scripts/viral_score.py --file samples/video.txt` 输出 7 维分 + 综合分 + 95% CI + 短板 Top2 + feature trace，退出码 0。
2. 同输入两次运行结果完全一致（固定 seed）。
3. AHP CR 计算正确：一致性矩阵 CR≈0（<0.01）；故意矛盾矩阵 CR>0.1 且被拒绝。
4. 熵权法在指标等值时给出均等权重且不除零。
5. TOPSIS 贴近度 ∈ [0,1]，全优样本→接近 1，全劣→接近 0。
6. `references/math-engine.md` 每条工具都有「何时用 / 公式 / 陷阱 / 解读」四要素。
