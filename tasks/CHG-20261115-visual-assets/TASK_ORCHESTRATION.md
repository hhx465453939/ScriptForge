## 关键实现约束

- **绘制顺序**：先定底（纸色）→ 再定分割（栅格与基线）→ 再上唯一强调色块 → 最后排字。颠倒顺序会把字压进几何里。
- **字永远压不过几何时，改几何**：v1 标记让两个形体相撞，32px 以下糊成噪点；v2 收成单形体后各尺寸均干净。图标的第一需求是缩小时不塌。
- **文字落色规则**：任何文字必须完全落在**单一纯色**区域内。横幅 v1 曾让奶白大字跨在红色斜切与纸色之间，导致半个字隐形 —— 固化为「实心面板」而非「斜切色带」承载文字。
- **SVG 空格折叠**：`<text>` 内连续空格会被折叠，微标签的多段文案必须拆成多个 `<text>`，不能靠空格排版。
- **字体回退**：不嵌 webfont，只写通用族名；渲染验收必须在实机 Chrome 里出图看，不能只看 XML 合法。
