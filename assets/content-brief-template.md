# 仿写脚本输出模板

> 本模板定义了仿写脚本的标准输出格式。每个品类的仿写脚本必须包含以下内容。

---

## 仿写脚本：[品类/产品名称]

### 基本信息

| 项目 | 内容 |
|------|------|
| 适用产品 | [产品名称] |
| 所用模型 | [模型名称，如"吐槽安利"] |
| 目标平台 | 抖音/小红书/快手 |
| 预估时长 | [X]秒 |
| 内容类型 | 种草/测评/口播/清单 |
| 预期效果 | [转化导向/品牌曝光/互动引流] |

### 完整文案

> [完整的口播文案，可直接用于拍摄]

### 段落功能标注

| 段落 | 文案（摘录） | 功能 | 情绪/手法 |
|------|-------------|------|-----------|
| 钩子段 | [开头1-2句] | [功能说明] | [手法] |
| 痛点段 | [...] | [功能说明] | [手法] |
| ... | ... | ... | ... |
| CTA段 | [结尾1-2句] | [功能说明] | [手法] |

### 拍摄建议（可选）

- **景别:** [近景/中景/特写建议]
- **场景:** [拍摄场景建议]
- **道具:** [需要的道具]
- **节奏:** [快节奏/中速/慢节奏]
- **BGM建议:** [音乐风格]

---

## 多品类仿写输出格式

当同时输出多个品类的仿写时:

```
### 仿写一：[品类A]
[完整文案]

### 仿写二：[品类B]
[完整文案]

### 仿写三：[品类C]（如有）
[完整文案]
```

每个仿写都遵循上述完整格式。
