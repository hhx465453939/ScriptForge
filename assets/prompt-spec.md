# 文生图 / 文生视频 提示词规范

> 本文件定义提示词的**冻结字段**。缺字段即不合格——因为字段缺一个，下游就得多猜一次。
>
> 定位：本项目**不生成图片与视频**，只产出可直接投喂给生成工具的**规格化提示词**。

---

## 1. 文生图：13 字段（冻结）

| # | 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|---|
| 1 | `id` | string | 唯一编号，与物料对应 | `img-01` |
| 2 | `subject` | string | 画面主体（人/物/场景核心） | `一只手拿着手机，屏幕显示文案评分表` |
| 3 | `scene` | string | 环境与背景 | `原木色桌面，笔记本旁有一杯咖啡` |
| 4 | `composition` | string | 构图（含主体位置与留白区） | `主体居左三分线，右侧 1/3 留白放标题` |
| 5 | `lighting` | string | 光线 | `侧逆光，暖调，柔和阴影` |
| 6 | `style` | string | 视觉风格 | `纪实摄影感，轻微胶片颗粒` |
| 7 | `palette` | string | 配色 | `米白 + 墨绿 + 砖红点缀` |
| 8 | `lens` | string | 视角与焦段 | `50mm，俯拍 30 度` |
| 9 | `negative` | string | 负面提示 | `无文字水印，无夸张滤镜，无变形手指` |
| 10 | `platform` | string | 目标平台（决定画幅） | `xiaohongshu` |
| 11 | `model` | string | 模型族 + 可用型号 | `通用图像模型 / <可用型号>` |
| 12 | `params` | object | `{aspect_ratio, seed}` | `{aspect_ratio: "3:4", seed: 12345}` |
| 13 | `usage` | string | 用途（放哪、配哪条文案） | `graphic-01 首图` |

### 1.1 写法要求

- `subject` + `scene` 必须**具体到可拍**，禁止「一个好看的场景」这类空话
- `composition` 必须说明**留白位置**——图文的图是配文字用的，不留白等于废图
- `negative` 不允许留空，至少写「无文字水印、无变形」
- 一条提示词只表达**一个视觉意图**，不要塞三个主体

## 2. 文生视频：11 字段（冻结）

| # | 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|---|
| 1 | `id` | string | 唯一编号 | `vid-01` |
| 2 | `shot_motion` | string | 镜头运动 | `缓慢推近（dolly in），由中景到特写` |
| 3 | `duration` | string | 时长（秒） | `6s` |
| 4 | `first_frame` | string | 首帧描述（决定观众第一眼） | `手机屏幕特写，显示「综合分 58.4」` |
| 5 | `style` | string | 影像风格 | `干净科技感，浅景深` |
| 6 | `negative` | string | 负面提示 | `无形变，无闪烁，无水印` |
| 7 | `platform` | string | 目标平台 | `douyin` |
| 8 | `model` | string | 模型族 + 型号 | `通用视频模型 / <可用型号>` |
| 9 | `params` | object | `{aspect_ratio, duration, fps}` | `{aspect_ratio: "9:16", duration: 6, fps: 24}` |
| 10 | `audio` | string | 声音设计（配音风格/字幕/BGM） | `男声干货口播，无 BGM，关键数字压字幕` |
| 11 | `usage` | string | 用途 | `video-01 第 2 个镜头` |

### 2.1 写法要求

- `first_frame` 是视频提示词里**最重要**的字段：多数平台按首帧决定是否划走
- `duration` 必须与所用平台的时长上限自查（见 §3）
- 一条提示词 = 一个镜头。多镜头拆多条，用 `id` 串起来（`vid-01a/b/c`）

## 3. 平台 × 模型适配矩阵（冻结列）

| platform | 画幅 | 时长上限 | 首帧偏好 | 文字区建议 | 推荐模型族 |
|---|---|---|---|---|---|
| `douyin` | 9:16 | 60s（带货 30–45s） | 强对比 + 大字 | 上 1/4 留标题，下 1/4 留字幕 | 通用视频模型 |
| `xiaohongshu` | 3:4 / 1:1 | 60s | 真实感、生活化 | 首图上方留 20% 放标题 | 通用图像 / 视频模型 |
| `shipinhao` | 9:16 | 60s | 稳、清晰 | 同抖音 | 通用视频模型 |
| `gongzhonghao` | 16:9 | 不限 | 信息图 / 长图 | 顶部通栏标题 | 图像模型 + HTML 排版 |
| `zhihu` | 16:9 | 不限 | 信息图 | 图表优先，少装饰 | 图像模型 |
| `x` / `twitter` | 16:9 | 140s | 强视觉冲击 | 中央大字 | 通用模型 |
| `github` | 16:9 | — | 仓库截图 + 数据图 | 顶部 banner 放项目名 | 截图 + HTML 渲染 |

**填写纪律**：`model` 写成「族名 / 具体型号」，型号未知时写 `通用图像模型 / UNKNOWN`，**不许只写「AI 生成」**。

## 4. 完整示例

### 4.1 文生图（小红书首图）

```yaml
id: img-01
subject: 一只手拿着手机，屏幕上是文案评分表（七行分数可见）
scene: 原木色书桌，旁边有笔记本、笔、一杯拿铁
composition: 手机居左三分线，右侧 1/3 大面积留白用于压标题
lighting: 上午侧向自然光，暖调，柔和阴影
style: 纪实摄影感，轻微胶片颗粒，不摆拍
palette: 米白主导，墨绿点缀，砖红小面积强调
lens: 50mm 定焦，俯拍 30 度
negative: 无文字水印，无夸张滤镜，无变形手指，无 AI 感过曝
platform: xiaohongshu
model: 通用图像模型 / <可用型号>
params: {aspect_ratio: "3:4", seed: 20261115}
usage: graphic-01 首图，配标题「我把爆款拆成了公式」
```

### 4.2 文生视频（抖音第 2 镜头）

```yaml
id: vid-01b
shot_motion: 缓慢推近，中景到屏幕特写
duration: 4s
first_frame: 电脑屏幕显示「综合分 58.4 / 分区 B」，光标停在「钩子力」一栏
style: 干净科技感，浅景深，屏幕光为主光源
negative: 无形变，无闪烁，无水印，无快速跳切
platform: douyin
model: 通用视频模型 / <可用型号>
params: {aspect_ratio: "9:16", duration: 4, fps: 24}
audio: 男声干货口播（语速偏快），无 BGM，数字出现时压入字幕
usage: video-01 第 2 个镜头，承接「别靠感觉」的口播
```

## 5. 校验规则（可脚本化）

| 规则 | 判据 |
|---|---|
| 图字段数 | 必须 = 13，缺一不合格 |
| 视频字段数 | 必须 = 11，缺一不合格 |
| `platform` 合法性 | 必须在 §3 矩阵内 |
| `params.aspect_ratio` | 必须与平台矩阵画幅一致 |
| `duration` | 视频不得超过平台上限 |
| `negative` | 不得为空 |
| `model` | 不得为空，且不得只写「AI 生成」 |
| `composition` | 必须含留白说明（关键词：留白 / 空白 / 区域） |

---

## 6. 反模式

| 反模式 | 后果 |
|---|---|
| 提示词写成散文（「一个温馨的场景」） | 生成结果不可控，10 次出 1 张能用 |
| 忽略留白 | 图没法配文字，等于废图 |
| 视频只写一句话不拆镜头 | 生成结果没有叙事 |
| `platform` 留空 | 画幅错，投错平台 |
| `model` 只写「AI」 | 下游无法执行 |
| 一条提示词塞多个主体 | 主体争夺注意力，画面散 |
