> 形态判定为兜底规则命中（置信度低）。如果你要按视频口播/长文拆解，请告诉我，我重跑。

## 📝 十一、完形填空模板（核心交付）

图文模板**必须含 4 个特有位置**：

1. **标题公式位**：`[______标题公式槽]`
2. **首图钩子位**：`[______首图钩子]`
3. **正文分段位**：按段给出骨架，每段一行
4. **标签位**：`[______标签组]`

```
[______标题公式槽：人群词 + 痛点/场景 + 爽点，控制在 12-18 字]

[______首段：一句话结论或场景切入，≤60 字]😮‍💨

[______第2段：痛点具体化 + 一个真实场景]

[______第3段：方案/产品出场，说清一个核心机制]

[______第4段：实测证据（数据/时长/对比结果）]

[______第5段：缺点或限定条件（真实感来源）]

[______第6段：CTA（收藏/关注/评论诱饵）]

# [______标签组：品类词 + 人群词 + 场景词 + 长尾词，共 4-8 个]
```

填写说明表（每个占位符一行，含 2 个跨品类示例）。
