# 量化评分卡模板（粘贴到任意拆解报告）

> 用法：跑完 `python scripts/viral_score.py --file 文案.txt --json`，按本模板把数字搬进报告。
> **纪律：报分必带区间、必带形态、必转述 reliability_notes。禁止裸标量。**

---

## 一、评分卡（复制这一段）

```markdown
### 🔥 爆款量化评估

| 项 | 值 |
|---|---|
| 形态 | {genre}（判定置信度 {高/中/低}） |
| 综合分 | **{score100} / 100** |
| 95% 置信区间 | [{ci.lo}, {ci.hi}]（{method}, B={n_boot}） |
| 分区 | **{band}**（S≥80 / A≥65 / B≥50 / C≥35 / D<35） |
| AHP 一致性 | CR = {ahp_cr}（需 <0.10） |
| 校准状态 | {calibration_status} |

**七维得分**

| 维度 | 分数 | 95% CI | 判定 |
|---|---|---|---|
| 钩子力 | {hook} | [{lo}, {hi}] | 强/中/弱 |
| 信息密度 | {density} | [{lo}, {hi}] | 强/中/弱 |
| 节奏冲击 | {rhythm} | [{lo}, {hi}] | 强/中/弱 |
| 情绪驱动 | {emotion} | [{lo}, {hi}] | 强/中/弱 |
| 说服转化 | {persuasion} | [{lo}, {hi}] | 强/中/弱 |
| 差异化 | {distinction} | [{lo}, {hi}] | 强/中/弱 |
| 可复制性 | {replicability} | [{lo}, {hi}] | 强/中/弱 |

**优势**：{strengths[0].label}（{score}）、{strengths[1].label}（{score}）
**短板**：{weaknesses[0].label}（{score}）、{weaknesses[1].label}（{score}）
**该形态最该补**：{priority_dimensions_for_genre}
```

## 二、权重来源（可审计，必须附）

```markdown
| 维度 | AHP 主观 | 熵权客观 | 组合 | 说明 |
|---|---|---|---|---|
| hook | {w} | {w} | {w} | — |
| ... | | | | |

组合赋权 α = {alpha}（主观占比）
```

**为什么要附**：权重是可被质疑的。用户问「凭什么是钩子权重最高」时，要能答出「AHP 先验 + 熵权客观区分度，CR=0.015 未超限，先验依据见 genres.py 的 priority 向量」。

## 三、可回溯特征（feature_trace 摘要）

只摘录与短板相关的，不用全量贴（全量在 JSON 里）：

```markdown
| 短板 | 相关原始读数 |
|---|---|
| 情绪驱动 0.34 | 情绪词 {n} 个（每百字 {x}）；情绪序列 σ={v}；CUSUM 变点 {k} 个 |
| 说服转化 0.39 | 信任锚 {n} 个；数字 {n} 个；CTA {n} 处（相对位置 {p}）；绝对化用语 {n} 个 |
```

## 四、可靠性提示（有则必转述）

```markdown
⚠️ 可靠性提示
- {reliability_notes 逐条}
```

常见三条及含义：

| 提示原文（片段） | 含义 | 对结论的影响 |
|---|---|---|
| 可复制性：结构转移样本不足 | 句数少，马尔可夫转移不可信 | 该维已折减 ×0.6，别据此判断套路化 |
| 信息密度：Zipf 拟合 R² < 0.70 | 词频不符合幂律 | 该项权重已被剔除，密度分只由前两项决定 |
| 节奏：句数 < 20，主周期不可信 | 短文本无法检测节奏周期 | 该子项取中性 0.5，不参与区分 |

---

## 五、结论纪律（三不许）

1. **不许**写「本分预测播放量约 X」——引擎只给形态内相对位置
2. **不许**跨形态比绝对分——video 60 ≠ graphic 60
3. **不许**把短板写成形容词就完事——必须给可执行改法：
   - ❌「情绪驱动偏低」
   - ✅「第 3–5 句零情绪词，建议在痛点处插入一个具体场景（如『早八赶地铁时衬衫全皱』）」

## 六、定点迭代建议模板

短板只有两个，改完再跑一次对比：

```markdown
### 迭代记录

| 轮次 | 修改动作 | 综合分 | 变化 | 短板变化 |
|---|---|---|---|---|
| 初稿 | — | 58.4 [51.2, 65.0] | — | 情绪 0.34 / 说服 0.39 |
| 第 1 轮 | 标题 22→16 字；段落 11→6 段 | 63.1 [56.0, 69.8] | +4.7 | 节奏 0.42 / 说服 0.41 |
| 第 2 轮 | 第 2 段插入场景；补 2 处信任锚 | 68.9 [61.4, 75.2] | +5.8 | 情绪 0.51 / 说服 0.55 |
```

**注意**：区间重叠时不要宣称「显著提升」。上例第 2 轮区间 [61.4, 75.2] 与初稿 [51.2, 65.0] 有重叠，只能说「有提升趋势」，不能说「确认提升」。
